## 📦 What's Inside?

This repository contains standalone files in the `widgets/` folder. You can preview and download them individually:

### 1. 🏛️ 3D Holographic Banner (`widgets/3d-hologram-banner.html`)
* **Description:** An interactive 3D particle field banner reacting dynamically to mouse movements, touch swipe gestures, and device gyroscope orientation sensors.
* **Tech:** Three.js, WebGL, CSS Volumetrics.

### 2. 🌌 Particle Logo Cloud (`widgets/particle-logo-cloud.html`)
* **Description:** Upload your own SVG paths and watch them assemble into a beautiful 3D cloud of glowing particles. Mouse hovering causes particles to dynamically scatter and regroup.
* **Tech:** SVGLoader, Three.js, Raycasting Physics.

### 3. ⚙️ Steampunk Chronometer (`widgets/steampunk-chrono.html`)
* **Description:** A retro-themed mechanical chronometer widget. Features realistic gear rotations, real-time hours/minutes/seconds hands synchronization, and dark glassmorphic styling.
* **Tech:** CSS Animations, HTML5 Canvas.

### 4. 🌐 Three.js Basic Scene Boilerplate (`widgets/threejs-basic-scene.html`)

## 🚀 How to Use

All files are fully standalone. To add a widget to your website, follow these simple steps:

1. Open the file in the `widgets/` folder of this repository (e.g., `widgets/steampunk-chrono.html`).
2. Copy the HTML code.
3. Paste the code into your own project.
4. (Optional) Adjust the styling variables or load your custom assets.
