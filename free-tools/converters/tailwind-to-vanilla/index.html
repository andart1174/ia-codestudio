Foire Aux Questions (FAQ) — Transpiler Tailwind en CSS

Comment convertir du HTML Tailwind en CSS Vanilla ?
Collez simplement votre code HTML contenant des classes utilitaires Tailwind dans la boîte de saisie. Notre transpiler intelligent analyse les classes et génère un code HTML propre avec du CSS standard intégré (inline) ou un fichier de feuille de style externe correspondant.
Pourquoi convertir du code Tailwind CSS en CSS standard ?
De nombreuses plateformes limitent l'utilisation de frameworks externes. Par exemple, lors de la création de modèles d'e-mails HTML, les clients de messagerie ne chargent pas les feuilles de style Tailwind externes et nécessitent du style CSS inline. Ce convertisseur automatise ce processus fastidieux.
Ce convertisseur prend-il en charge toutes les classes Tailwind CSS ?
Oui, notre transpiler intègre un dictionnaire complet qui prend en charge la grande majorité des classes utilitaires de Tailwind (espacements, flexbox, grille, couleurs HSL/RGB, bordures, ombres et typographies) et les traduit fidèlement en CSS standard.
Est-il utile pour créer des e-mails HTML ?
Absolument. C'est l'un des cas d'usage principaux. Vous pouvez concevoir votre modèle d'e-mail très rapidement en utilisant Tailwind dans votre éditeur préféré, puis utiliser cet outil pour compiler le résultat en un seul fichier HTML autonome, prêt à être envoyé avec les styles CSS injectés directement dans chaque balise.
