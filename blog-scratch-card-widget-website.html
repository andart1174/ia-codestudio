Technical Details: How It Works

HTML5 Canvas Technology

The scratch card widget uses the HTML5 Canvas API to simulate the scratching effect. This is the same technology used by professional lottery apps. It works on all modern browsers — Chrome, Firefox, Safari, Edge — on both desktop and mobile, with no plugins or downloads required.

Touch & Mouse Support

The widget automatically detects whether the user is on a touchscreen or using a mouse. On desktop, click and drag reveals the prize. On mobile, use your finger to scratch. The sensitivity and scratch percentage (how much area to reveal) can be customized.

Zero Dependencies

The exported HTML file is completely self-contained. It doesn't load any external libraries or make any external requests — just pure HTML, CSS and vanilla JavaScript. This means it loads instantly and works even with strict Content Security Policies.
