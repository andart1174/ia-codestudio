Install on Phone & Tablet (PWA Guide)

Install HyperStudio 3D & Pilot Simulator as a standalone native app with full-screen view and maximum 60FPS performance:

Android (Chrome / Edge)

  1. Open this page in Google Chrome.
  2. Tap the 3 dots menu (⋮) in the top-right corner.
  3. Select "Install app" (or "Add to Home screen").
  4. The app icon will appear directly on your home screen!

iPhone & iPad (Safari)

  1. Open this page in Apple Safari.
  2. Tap the Share button (⎋) in the toolbar.
  3. Scroll down and tap "Add to Home Screen" (➕).
  4. Tap "Add" in the top-right corner.

Open from PC to Phone / Tablet (Local Wi-Fi Network)

To access the studio from any phone or tablet on the same Wi-Fi:

1. Start a local web server (e.g. Live Server extension or run: npx serve) 2. Open your PC local IP address on mobile (e.g. http://192.168.1.X:5500) 3. Or deploy free on GitHub Pages / Vercel / Netlify for instant global access!
